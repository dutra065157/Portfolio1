# 📊 Portfólio de Business Intelligence & Desenvolvimento Web

Bem-vindo ao repositório do meu portfólio profissional. Este projeto reúne meus dashboards interativos de Power BI e demonstrações de aplicações web, focados em transformar dados complexos em insights acionáveis para tomada de decisão.

🔗 **Acesse o Portfólio Online:** [Visualizar Projeto](https://dutra065157.github.io/Portfolio1/)

## 🚀 Sobre o Projeto

Este portfólio foi desenvolvido como uma Single Page Application (SPA) responsiva para apresentar meus projetos de análise de dados. O objetivo é demonstrar não apenas a capacidade analítica, mas também a habilidade de integrar soluções de BI em ambientes web modernos.

### Principais Funcionalidades:

- **Dashboards Embarcados:** Integração direta com o Power BI Service.
- **Design Responsivo:** Interface adaptável para mobile e desktop utilizando Tailwind CSS.
- **Filtros Dinâmicos:** Navegação por categorias (Vendas, RH, Logística, etc.).
- **Integração Web:** Demonstração de App Web consumindo API REST.

## 🛠️ Tecnologias e Ferramentas

### Análise de Dados & BI

- **Power BI:** Criação de dashboards interativos e storytelling de dados.
- **DAX (Data Analysis Expressions):** Criação de medidas complexas e colunas calculadas.
- **Power Query (M):** ETL (Extração, Transformação e Carga) e limpeza de dados.
- **SQL / SQL Server:** Consultas e manipulação de banco de dados.
- **Excel:** Análise exploratória e fontes de dados.
- **Python:** Scripting para automação e análise (mencionado no perfil).

### Desenvolvimento Web (Front-end)

- **HTML5 & CSS3:** Estrutura semântica e estilização.
- **Tailwind CSS:** Framework CSS utilitário para design rápido e responsivo.
- **JavaScript:** Lógica de interação do menu e filtros.
- **Font Awesome:** Ícones vetoriais.

## 📈 Projetos em Destaque

O portfólio inclui análises detalhadas nas seguintes áreas:

1.  **Logística:** Análise de entregas, prazos (SLA), performance por equipe e canal de entrega.
2.  **Vendas (Varejo Global):** Faturamento, lucro, análise por continente/país e tendências temporais.
3.  **Recursos Humanos (RH):** Headcount, diversidade, média salarial e análise de horas extras.
4.  **App Web Loja:** Uma aplicação web integrada hospedada no Render, demonstrando consumo de API e visualização em tempo real.
